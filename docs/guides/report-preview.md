# 报告里的视频无法加载

报告通常引用原录播或已生成的成片，不会把视频打包进 HTML。网页预览环境可能禁止读取 `file:///C:/...` 这类本机路径；原文件存在、格式正常时也可能一直显示 0:00。这与视频是否已经剪出是两件事。

## 打开方式

在资源管理器中找到报告，双击同目录的 `open_preview.cmd`。它会打开本机浏览器和一个仅供本机访问的预览服务。保留命令窗口，按 Ctrl+C 结束预览。

旧报告没有启动文件时，从项目根目录运行：

```bat
.\.venv\Scripts\python.exe -X utf8 -m scripts.preview_report --report "outputs\你的任务目录\report.html"
```

报告在其他盘符、原录播在下载文件夹时也可使用。预览会将报告明确引用的图片和视频转换为本机地址，并支持视频按时间定位所需的字节范围请求；不复制整场录播，不重新转写、请求模型或编码。

## 仍无法播放时

- 原文件是否被移动或重命名？服务不会替你猜测另一份录播。
- 用本机 Chrome 或 Edge 打开预览命令给出的地址，不在其他网站的 HTML 预览框里打开本机视频路径。
- 报告是否只是选片分析？它播放的是原录播区间，并不代表已经有 `clip.mp4`。
- 文件本身若使用浏览器不支持的编码，需要另行处理；预览服务不会偷偷转换原视频。

服务只绑定 `127.0.0.1`，只开放报告明确引用且允许的文件类型，不提供项目目录列表或任意文件读取。它是本机回看工具，不是公网托管服务。

实现依据：[浏览器同源限制](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)、[HTTP 范围请求](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Range_requests)。
