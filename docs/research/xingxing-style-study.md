## 已实现的变化

- 默认封面样式 `publication.cover_style=live_reaction`：真实场景裁切、黄/粉/青/白大字、粗黑描边。支持左/右排字及顶部+底部排字；旧版 `quote_poster` 仍可配置使用。
- 通过本地实际看图标注焦点、缩放、排字侧和片内取帧时间。明确标注的帧优先于全局对比度打分，避免程序把“最亮的一帧”误当成“最合适的表情”。没有标注的新素材默认保留全景，在顶部和底部排字。
- 封面文字区分 `quote`（连续字幕原话）和 `caption`（编辑概括）。概括记录所引字幕原文，但不伪装为主播说过的台词。解决了“不要跟番茄一起炖”跳字改写导致整条没有封面的旧故障；原话仍严格校验，不整体关闭证据检查。
- 标题提示词采用具体事件、数字、物件、原话与后续发展；过滤部分无证据的规模、动作和情绪描述。读弹幕要求加钟不能写成主播主动加钟。引用 ID 只保证证据存在，不代表语义自动核实。
- 新增 `render.subtitle_style.emphasis_mode=phrase`：字幕底色保留黄字，只给经过校验的短语换色，不放大整条长字幕。强调不改字、不改原字幕时间；概括文字不会被烧成说话字幕。`cue` 保留旧的整句强调，`none` 关闭强调。
- 选片提示词增加完整角色扮演、方言反差、读弹幕后发挥等具体偏好，保留自然铺垫和收尾；没有增加片内自动跳剪。

## 使用与复核

在项目目录运行：

```powershell
.\run_clips.cmd --restyle
```

此模式复用转写和选片。已有有效本地文案复核时不调用投稿模型；未复核的新片段会调用配置中的模型。字幕呈现有变化时重新编码，只有标题/封面变化则复用视频。

只根据分析中已经保存的文案重做封面，可运行 `.\run_clips.cmd --package-only`，不调用 API，也不编码；它不会重新读取尚未应用的文字或构图复核文件。

输出 `ouput/report.html` 提供成片、默认封面、备选封面、标题、简介与证据。每个 `clips/<ID>/` 包含 `clip.mp4`、`cover.jpg`、3 张候选封面、标题候选和投稿文案。

当前批次的 `cover_focus.json` 结构如下，坐标范围 0–1，时间单位为原视频毫秒：

```json
{
  "source": {"path": "原录播绝对路径", "size": 123, "mtime_ns": 456},
  "clips": {
    "12位片段ID": {
      "focus": [0.5, 0.4],
      "zoom": 1.4,
      "text_side": "right",
      "frame_ms": 601000
    }
  }
}
```

允许的缩放为 1–3.5，排字侧为 `left/right/bands`；片内取帧时间必须在该切片起止内。旧版 `[x,y]` 焦点标注兼容。新素材没有视觉定位或经过看图的标注时，程序不会假称已选出最佳表情；自动文字生成仍需复核 ASR 专名、说话人和具体事实。原视频已经烧录的弹幕无法通过重新下载字幕关闭，选帧与裁切只能部分减少遮挡。
