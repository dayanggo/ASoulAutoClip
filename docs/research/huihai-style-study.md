这些样本中可见的共同方法：

| 项目 | 观察 | 本项目改法 |
| --- | --- | --- |
| 标题 | 说清人物、发生的事、原话或前后反差，像观众向别人分享看点 | 选片标签和投稿标题分离；单独读完整片段，生成最多 3 个标题 |
| 封面文字 | 很多是具体原话；有单句，也有多行对话，不全是极短大字 | 选 1–3 行字幕原话，与标题互补；每行绑定字幕证据 |
| 字体 | 粗体、醒目的彩色字、多层描边，缩略图下仍可辨识 | 暖黄、粉、浅蓝的候选配色；深色外边和浅色内边；取消通用标签、时间码 |
| 画面 | 原始人物/游戏现场，不同视频采用不同构图 | 从关键句附近取帧；有人工焦点标注时做人物近景，无标注时保留完整场景 |
| 内容组织 | 有独立笑点的短互动和数分钟完整事件都存在；抽样不支持“固定几十秒” | 保留现有证据和事件边界，突出关键字幕，不强加固定时长或机械跳切 |

仅凭这些样本无法判断点击率、完播率，不能保证改版后数据一定提升。未复制作者的名字、头像、标识或片尾。当前改进是明确的编辑方法与画面排版调整，不是已经实现了人工剪辑师的视觉理解能力。

## 程序中的实际变化

`core/clip_editorial.py` 与 `prompts/clip_editorial_zh.txt` 是新增的投稿编辑阶段。它调用已配置的大模型 API，读片段内全部字幕，生成投稿标题候选、封面原话、取帧句和重点字幕 ID。该阶段独立缓存，修改文案提示词不影响 ASR 和选片缓存。

代码会验证引用 ID、封面原话和标题中的引语。封面最终的引文由程序从字幕提取；如果一句话被 ASR 拆成紧邻的两段，可引用两段，元数据记录所有 ID；遇到改写的封面文字，只允许退回已验证的短引语。少量动作/情绪词有保守过滤，但这些检查不能自动证明改写标题的所有语义都准确。ASR 听错的词仍可能影响结果，需要看报告复核。模型不接收视频画面，不会自动识别人物表情或定位人脸。

`core/clip_publication.py` 改成关键句附近取帧、独立封面文案、多层描边和可选人物近景。对比度只用于排除暗帧，不再把它描述为“识别最佳表情”。`core/highlight_render.py` 在少量重点原话上增加字号和颜色强调，不添加无证据的旁白、不打乱事件顺序。标题或封面修改不会使相同内容的视频重复编码。

目前 7 条片段的边界保持原样。改善的是投稿表达、封面和字幕强调，还没有完成视觉模型审片、自动去除烙在录播里的弹幕、内部无损跳剪或自动投稿。对参考视频的观察也不足以证明应该对所有直播素材使用这些处理。

## 已有结果更新

```powershell
.\run_clips.cmd --restyle
```

这会读取当前输出目录的 `analysis.json` 和 `transcript.indexed.json`，验证录播一致后复用已选片段，调用投稿编辑 API 并更新重点字幕、封面及文案。第一次会因字幕强调重新编码，后续复用有效缓存。API 会产生服务用量；失败可重跑。旧成片在新视频通过检查后才被替换。

```powershell
.\run_clips.cmd --package-only
```

这个命令仍然离线：只用已有编辑结果补齐封面和文案，不调用 API、不重新编码。

以后照常运行 `.\run_clips.cmd` 即可使用新阶段。设 `publication.editorial_enabled=false` 可关闭投稿编辑 API；`publication.enabled=false` 可关闭封面和文案生成。

## 可选人工构图标注

输出目录 `cover_focus.json` 可以提供原画面归一化焦点，`[0.5,0.4]` 表示画面宽度 50%、高度 40%。顶层 `source` 必须和 `analysis.json` 完全一致，`clips` 以切片 ID 为键。没有标注的片段采用全景封面。本次 6 条人物构图由实际截图人工标注，番茄竞拍保留全景；这些标注不能推广为自动视觉识别。

```json
{"source":{"path":"与 analysis.json 一致","size":123,"mtime_ns":456},"clips":{"片段ID":[0.5,0.4]}}
```

`editorial.overrides.json` 用相同的 `source` / `clips` 结构保存人工复核过的投稿编辑结果，字段同 `clip_editorial_zh.txt` 中的输出结构。运行 `--restyle` 时，存在完整复核条目的切片会直接验证并采用这些条目，不再为该切片请求编辑 API；其余切片仍自动生成。人工条目同样必须通过片内 ID 和原话校验。报告的标题、封面和重点字幕会同步更新，分析中记录 `origin=local_review`。

当前 7 条的最终稿经过本次逐条核对；自动草稿仍独立留在缓存，不能把本次人工复核后的效果当作所有未来素材的自动效果。
